# Planejamento do Projeto — SkillMatch JS

## Ferramenta utilizada

O planejamento e acompanhamento do projeto foi realizado utilizando o **Jira**, organizando as tarefas em um quadro Kanban com as colunas:

**Backlog → A Fazer → Em Andamento → Concluído**

🔗 Acesse o quadro: [Projeto-SkillMatch no Jira](https://marialk-senai-frontend.atlassian.net/jira/software/projects/SCRUM/boards/1?atlOrigin=eyJpIjoiNWM3ZjA2ZGJhYmU3NGU2NmI0MGJmMjg3YWRjMjdjN2YiLCJwIjoiaiJ9)

> > O quadro está acessível publicamente via link.

---

## Como foi organizado

As tarefas foram separadas em **épicos**, onde cada épico representa uma grande área de desenvolvimento do projeto. Dentro de cada épico foram criadas **subtarefas** detalhando cada atividade realizada.

---

## Épicos e atividades

### 🟦 Estrutura Inicial do Projeto
Responsável pela configuração inicial do ambiente de desenvolvimento.

- Criar repositório GitHub
- Criar branches (main, develop, feat/analise-vagas, docs/readme)
- Criar estrutura de arquivos (skillmatch.js, README.md e planejamento/kanban.md)
- Configurar Jira

---

### 🟩 Modelagem de Dados
Responsável pela criação das classes e dados utilizados pelo sistema.

- Criar classe Candidato e instanciar objeto candidato
- Criar classe Vaga
- Criar classe VagaFrontEnd com herança
- Criar array de vagas fictícias
- Validar estrutura dos dados criados

---

### 🟨 Sistema de Compatibilidade
Responsável pela lógica principal de análise e comparação de perfis.

- Criar função para identificar habilidades encontradas
- Criar função para listar habilidades faltantes
- Criar função para calcular compatibilidade
- Criar classificação por percentual
- Criar análise completa das vagas
- Identificar vaga com maior compatibilidade
- Gerar recomendação de estudo

---

### 🟥 Recursos Avançados JavaScript
Responsável pela implementação dos recursos avançados exigidos no projeto.

- Implementar métodos de array (map, filter, reduce)
- Criar função com callback
- Criar função com closure
- Criar Promise simulada
- Criar função async/await
- Testar recursos avançados no console

---

### 🟪 Finalização do Projeto
Responsável pela documentação, testes finais e entrega.

- Atualizar README.md
- Revisar commits e branches
- Realizar testes finais do sistema
- Gravar vídeo de apresentação
- Preparar links de entrega
- Enviar projeto no AVA
